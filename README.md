# Forest Fire Prediction Using AI and Green Skills

This project predicts the occurrence of forest fires based on environmental features using machine learning models like Random Forest, Logistic Regression, SVM, and more.

## Dataset
- Source: [UCI Forest Fire Dataset](https://www.kaggle.com/datasets/johndasilva/forest-fires-data) (you can upload it to GitHub or link to Kaggle)

## Models Implemented
- Random Forest
- Logistic Regression
- SVM
- KNN
- Decision Tree
- Naive Bayes

## How to Run
1. Upload forestfires.csv to your Colab session.
2. Run the Jupyter notebook: Forest_Fire_Prediction_6_Implementations.ipynb.

## Results
- Shows accuracy, confusion matrix, and 3D PCA plot for visual analysis.

## Green Skill Connection
Promotes AI-based fire risk analysis to support sustainable environmental practices.
